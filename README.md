# Une petite mission pour Madame

Mini-site interactif responsive pour une date du vendredi 21 août.

## Utilisation locale
Ouvrir `index.html` dans un navigateur.

## GitHub Pages
1. Crée un repository GitHub.
2. Mets-y `index.html`, `style.css`, `script.js` et le dossier `images/`.
3. Dans Settings → Pages, active GitHub Pages depuis la branche principale.
4. Partage l'URL générée.

Les deux dernières propositions sont volontairement des placeholders et peuvent être modifiées directement dans `index.html`.
